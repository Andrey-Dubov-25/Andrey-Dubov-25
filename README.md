`Python` `Django (DRF)` `Pytest` `PostgreSQL` `Docker` `Redoc`

**[Departments](https://github.com/Andrey-Dubov-25/departments)** -

`Python` `Django (DRF)` `Pytest` `PostgreSQL` `Docker` `Redoc`
